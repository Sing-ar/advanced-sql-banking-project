**Banking SQL & Machine Learning Analysis Project**

**Project Overview**
This project combines SQL-based banking analytics with Machine Learning techniques to analyze customer financial behavior, identify customer segments, and classify credit risk profiles.

**The project demonstrates end-to-end analytical workflows including:**
- Data cleaning and transformation
- SQL-based business analysis
- Customer segmentation using clustering
- Credit risk classification using machine learning

The project simulates real-world banking analytics and showcases skills relevant to Data Analytics, Data Engineering, and Machine Learning roles.

**Dataset**
Dataset Source:
Kaggle Synthetic Banking Dataset

**Dataset Tables**
The dataset includes:
- Customers
- Accounts
- Loans
- Credit Scores

**Machine Learning Techniques Used**
**Customer Segmentation**
Implemented K-Means Clustering to group customers based on financial and banking behavior.
Features used:
- Credit score
- Account balance
- Loan amount
- Debt ratio
- Interest rate
  
**Credit Risk Classification**
Built a Logistic Regression model to classify high-risk customers based on:
- Debt ratio
- Credit score
- Financial activity patterns

**Data Preprocessing**
Applied preprocessing techniques including:
- Feature scaling using StandardScaler
- Feature selection
- Dimensionality reduction using PCA

**Model Evaluation**
Evaluated classification performance using:
- Confusion Matrix
- Precision
- Recall
- F1-Score
