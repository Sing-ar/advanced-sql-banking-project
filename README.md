**Banking Analytic SQL**

**The project demonstrates end-to-end analytical workflows including:**
- Data cleaning and transformation
- SQL-based business analysis

The project simulates real-world banking analytics and showcases skills relevant to Data Analytics, Data Engineering.

**Dataset**
Dataset Source:
Kaggle Synthetic Banking Dataset

**Dataset Tables**
The dataset includes:
- Customers
- Accounts
- Loans
- Credit Scores

**SQL Skills Demonstrated**
This project applies practical SQL techniques used in analytical and reporting workflows:
- SELECT Statements
- JOIN Operations
- GROUP BY & ORDER BY
- CASE WHEN Logic
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions
- Subqueries
- Data Cleaning & Transformation
