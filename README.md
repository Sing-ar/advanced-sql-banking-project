**Banking SQL Analysis Project**

Dataset
Dataset Source:  
https://www.kaggle.com/datasets/akrambelha/synthetic-banking-dataset-csv-sql-sqlite

The dataset includes:
- Customers
- Accounts
- Transactions
- Loans
- Credit Scores
- Merchants

**Tool**
- SQL Server

**SQL Skills Used**
- SELECT
- JOIN
- GROUP BY
- ORDER BY
- CASE WHEN
- Common Table Expressions (CTE)
- Window Functions
- Aggregate Functions
- Data Cleaning
- Subqueries

**Example Analysis**
Some analyses performed in this project:
- Customer segmentation by credit score
- Monthly transaction
- Top customers by account balance
- Loan distribution analysis
